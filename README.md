# Agentic Workflow for Literature Synthesis

A human-supervised multi-agent system for scientific literature retrieval, knowledge extraction, knowledge organization, and literature synthesis.

## Architecture

Four specialized agents:

1. Literature Search Agent
2. Knowledge Extraction Agent
3. Knowledge Organization Agent
4. Literature Generation Agent

The system implements configurable human-in-the-loop review policies and evidence-grounded research workflows.
